# University Management System

## Project Purpose
This is a simple Python-based University Management System that manages students, courses, instructors, and enrollments.  
It demonstrates object-oriented programming, file handling, and a menu-driven interface.

---

## Features
- Add Students
- Add Courses
- Add Instructors
- Enroll Students in Courses
- View Students and Courses
- Menu-driven interface

---

## How to Run
1. Open project in PyCharm
2. Run `main.py`
3. Use the menu in terminal

---

## Technologies Used
- Python
- Object-Oriented Programming
- File Handling (CSV)
- Exception Handling
- Modular Programming

---

## Project Structure
- `main.py` → Entry point
- `models/` → Classes (Student, Course, Instructor)
- `system/` → Core logic (Enrollment Manager)
- `utils/` → File handling
- `data/` → Stored CSV data
